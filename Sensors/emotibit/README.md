# EmotiBit

- This repository is specifically for bridging the [EmotiBit sensors](https://www.emotibit.com/).


#### Folder Contents

Each folder has its own README with instructions on installation and usage.
- [emotibit_sdk](Sensors/emotibit/emotibit_sdk)
    - This folder includes a ROS2 package to publish EmotiBit data to a ROS node using **BrainFlow SDK**.
