# EmotiBit

- This repository is specifically for bridging the [EmotiBit sensors](https://www.emotibit.com/).


#### folder contents

- emotibit_oscilloscope
- emotibit_sdk

The *emotibit_oscilloscope* folder includes a ROS2 package to publish EmotiBit data to a ROS node using **Pylsl (requires EmotiBit Oscilloscope)**. 
The *emotibit_sdk* folder includes a ROS2 package to publish EmotiBit data to a ROS node using **BrainFlow SDK**.

More information can be found in the README of the respective folder.
