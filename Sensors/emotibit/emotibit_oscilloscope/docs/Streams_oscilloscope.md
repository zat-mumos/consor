# Streams from Oscilloscope

This markdown consists of a list of all streams that can be acquired using Emotibit in combination with the Emotibit Oscilloscope.

1. Accelerometer (3 streams: 1 per channel)
2. Gyroscope (3 streams: 1 per channel)
3. Magnetometer (3 streams: 1 per channel)
4. PPG (3 streams: Red, Green, Infrared)
5. Thermopile
6. Temperature
7. EDA
8. HeartRate
9. SCR (3 streams: Frequency, Amplitude, RiseTime)


Total number of streams that we can obtain are 19 streams. These are provided as parameters to the ROS node and their corresponding topics can be found [here](Sensors/emotibit/emotibit_oscilloscope/emotibit_oscilloscope/config/emotibit_params.yaml)
