# Install 'empty' package 

#### Download empty

- Download the zip file for the empty package (https://sourceforge.net/projects/empty/) or use an existing/downloaded empty package (.zip file)
- Version of empty tested with eSense is empty-0.6.23c

- Extract the empty folder
- Save the extracted folder in /home

- Open a new terminal
- cd empty-0.6.23c

- make

- sudo make install


#### Check if empty is installed

- cd

- To show the manual pages of empty <br>
man empty 

- To show the location where empty is installed <br>
which empty

- To show the version of empty that is installed <br>
empty -v
